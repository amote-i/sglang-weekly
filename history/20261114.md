## 新增参数

| 前一个参数/新参数分组 | 参数名称 | 默认值 | 可选值 | 描述 |
|---|---|---|---|---|
| --disaggregation-ib-device | --disaggregation-max-top-logprobs-num | 128 | Type: int | Largest top_logprobs_num a PD request can use: the width of the metadata buffer that carries the first output token's top logprobs from prefill to decode. Set the same value on both roles. Default is 128. |
| --mamba-max-states-per-path | --hybrid-cache-checkpoints-level | 2 | 2, 3 | Where a hybrid model's prefix cache checkpoints recurrent state. 2: branching points and request ends only (a PD prefill worker's end is its complete prompt), with a soft cap of one state per path. Host and storage tiers receive published states; models that also have sliding-window layers still checkpoint every chunk. 3: every prefill chunk and decode tracking boundary. |
| --paged-experts-enable-disk | --paged-experts-host-memory-gb | None | Type: float | Pinned host memory (GiB) for the experts of all MoE layers with --enable-paged-experts. When not every expert fits, each layer keeps only some experts in pinned memory and reads the others from its file under $SGLANG_CACHE_DIR/paged_experts, which needs --paged-experts-enable-disk. Unset: every expert is pinned; with --paged-experts-enable-disk, the experts that do not fit what is available at startup within the container's memory limit go to disk, keeping 10 GiB free. |
| --media-url-max-file-size-mb | --media-url-timeout | None | Type: float | Seconds to download one client-supplied media URL, redirects and body included, for every media type. When unset, REQUEST_TIMEOUT applies, else each loader's default. |
| --media-url-timeout | --allow-local-media-files | True | bool flag (BooleanOptionalAction, --no- prefix disables) | Allow client media to name local files (paths or file:// URLs). Enabled by default; use --no-allow-local-media-files to reject them. |
| --is-embedding | --disable-normalize-embedding | False | bool flag (set to enable) | Disable the L2 normalization the embedding Pooler applies after pooling, returning the raw pooled vector. Only affects models whose Pooler is built with normalize=True; custom poolers (cross-encoder, BERT pooler, vision pooler) are unaffected. |
| --log-requests-target | --log-schedule-decisions | False | bool flag (set to enable) | Log the outcome of every prefill pass that evaluates the waiting queue: picked vs left in queue, running and preempted counts, KV free/evictable tokens, and the picked rids (first 16). Logged on attention TP/CP rank 0 only. Passes that return early (e.g. running batch full, no free request slots) are not logged, and a pass that picks nothing is logged only when its counters differ from the previous empty pass. Verbose, so off by default. |
| --enable-layernorm-sp | --layernorm-sp-min-tokens | 0 | Type: int | With --enable-layernorm-sp, run a pass sequence-parallel only above this token count; smaller passes take the replicated path. 0 (the default) runs every extend sequence-parallel, as today. The SP collectives cost the same per layer whatever the pass size, so small extends -- short follow-up turns, small chunks, prefix-cache hits -- can be slower sequence-parallel than replicated while large chunks are faster. The crossover is deployment-specific: measure extend passes of a few sizes on both paths. Must be a captured prefill CUDA graph bucket, or at or above the largest one. |
| --schedule-policy | --shortest-prefill-aging-factor | 0.0 | Type: float | With --schedule-policy shortest-prefill-first, each prefill token processed while a request waits lowers its rank by this many tokens, bounding its wait to about its uncached length divided by the factor, in processed tokens. 0 disables aging. |
| --speculative-draft-kv-cache-dtype | --speculative-dspark-lm-head-dtype | None | fp8, mxfp8 | DSPARK only. Quantized dtype for the draft's projection through the target lm_head; the weight is quantized once and cached (about one extra byte per lm_head parameter). 'fp8' runs torch._scaled_mm and requires gfx95x; 'mxfp8' runs FlashInfer's CuTe DSL mm_mxfp8 and requires Blackwell. Target verify logits are unaffected. Default keeps the lm_head's own dtype. |
