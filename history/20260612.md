## 新增参数

| 前一个参数/新参数分组 | 参数名称 | 默认值 | 可选值 | 描述 |
|---|---|---|---|---|
| CUDA graph config: canonical JSON entry（新分组） | --cuda-graph-config | None | Type: parse_cuda_graph_config_arg | Per-phase CUDA graph settings as JSON, e.g. '{"decode":\{"backend":"full","max_bs":256\},"prefill":\{"backend":"tc_piecewise","tc_compiler":"eager"\}\}'. Allowed backends per phase: full, breakable, tc_piecewise, disabled (full is decode-only). JSON wins over the per-phase --cuda-graph-* convenience flags and over legacy flags. |
| CUDA graph: per-phase convenience flags（新分组） | --cuda-graph-backend-decode | None | full, breakable, tc_piecewise, disabled | Backend for the decode phase. Folds into cuda_graph_config[decode].backend. |
| --cuda-graph-backend-decode | --cuda-graph-backend-prefill | None | full, breakable, tc_piecewise, disabled | Backend for the prefill phase. Folds into cuda_graph_config[prefill].backend. |
| --cuda-graph-backend-prefill | --cuda-graph-max-bs-decode | None | Type: int | Maximum batch size captured for the decode cuda graph. |
| --cuda-graph-max-bs-decode | --cuda-graph-max-bs-prefill | None | Type: int | Maximum batch size captured for the prefill cuda graph. |
| --cuda-graph-max-bs-prefill | --cuda-graph-bs-decode | None | Type: List\[int\] | Explicit list of batch sizes to capture for the decode cuda graph. |
| --cuda-graph-bs-decode | --cuda-graph-bs-prefill | None | Type: List\[int\] | Explicit list of batch sizes to capture for the prefill cuda graph. |
| --cuda-graph-bs-prefill | --cuda-graph-tc-compiler | None | eager, inductor | Compiler used by the tc_piecewise backend (currently only the prefill phase consumes it). |
| --enable-attn-tp-input-scattered | --enable-prefill-cp | False | bool flag (set to enable) | Enable context parallelism for the prefill phase. Select the layout with --cp-strategy. |
| --enable-prefill-cp | --cp-strategy | None | zigzag, interleave | Sharding strategy for prefill CP. 'zigzag' is the former in-seq-split mode; 'interleave' is the former round-robin-split mode. |
| --encoder-urls | --encoder-bootstrap-port | 8997 | Type: int | Port for the EncoderBootstrapServer that runs in the language-only tokenizer manager process. Encoders register here, and language-only receivers fetch the current URL list from here. |
| --encoder-bootstrap-port | --encoder-register-urls | \[\] | Type: List\[str\] | One or more EncoderBootstrapServer URLs to register this encoder with on startup, for dynamic encoder discovery. Example: --encoder-register-urls http://prefill0:8997 http://prefill1:8997. Used with --encoder-only servers. |
