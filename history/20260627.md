## 新增参数

| 前一个参数/新参数分组 | 参数名称 | 默认值 | 可选值 | 描述 |
|---|---|---|---|---|
| --rl-quant-profile | --enable-tf32-matmul | False (may be set to True in `__post_init__` for Glm4Moe/MiniMaxM2) | bool flag (set to enable) | Enable float32 matmuls to use TensorFloat32 precision for better performance (via torch.set_float32_matmul_precision). CUDA only. |
| --enable-streaming-session | --enable-session-radix-cache | False | bool flag (set to enable) | Hold per-session KV as ordinary evictable radix entries, tagged by session id and bulk-evicted on close. Requires --radix-eviction-policy priority. |
| --speculative-adaptive-config | --decoupled-spec-bind-endpoint | None | Type: str | ZMQ endpoint this engine binds for its inbound channel in decoupled speculative decoding (verifier: result PULL; drafter: control PULL). |
| --decoupled-spec-bind-endpoint | --decoupled-spec-connect-endpoints | None | Type: str | Peer inbound (bind) endpoints to connect to, ordered by peer rank, for decoupled speculative decoding. |
| --decoupled-spec-connect-endpoints | --decoupled-spec-rank | None | Type: int | This engine's rank within its own role space (verifier-rank or drafter-rank) for decoupled speculative decoding. |
| --decoupled-spec-rank | --decoupled-spec-role | null | null, verifier, drafter | Role in decoupled speculative decoding: 'null' disables it, 'verifier' runs the target/verify half, 'drafter' runs the draft half. |
| --decoupled-spec-role | --spec-trace-dir | None | Type: str | Directory to write decoupled speculative decoding trace files. |
| --mamba-full-memory-ratio | --mamba-radix-cache-strategy | auto (set in `__post_init__`, initial value: auto) | auto, no_buffer, extra_buffer, extra_buffer_lazy | The strategy to use for mamba radix cache. |
| --linear-attn-prefill-backend | --enable-linear-replayssm | False | bool flag (set to enable) | Enable the ReplaySSM buffered output-only linear-attn decode kernel. Primarily a GDN (scalar-gate) decode-bandwidth optimization (~1.2-1.5x at batch >= 64). The unified kernel also supports KDA (per-K gate) and is numerically correct, but KDA decode is SLOWER than the packed baseline (the per-K g_cache is K x larger and the reconstruction refolds the per-K decay every step), so it is not recommended for KDA models. Requires the Triton linear-attn decode backend and --mamba-scheduler-strategy no_buffer (the default). |
| --enable-linear-replayssm | --linear-replayssm-cache-len | 16 | Type: int | Ring-buffer length L for ReplaySSM linear-attn decode. The full recurrent state is flushed to HBM every L decode steps. |
| --num-reserved-decode-tokens | --disaggregation-decode-extra-slots | None | Type: int | Number of extra decode req_to_token slots pre-allocated for in-transfer requests (PD mode). If unset, defaults to 0 (or 2x the per-worker running batch for small batches). |
