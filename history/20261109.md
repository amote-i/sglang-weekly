## 新增参数

| 前一个参数/新参数分组 | 参数名称 | 默认值 | 可选值 | 描述 |
|---|---|---|---|---|
| --enable-deepseek-v4-fp4-indexer | --enable-fp4-indexer | False | bool flag (set to enable) | Use FP4 queries and index-K cache in the DSA lightning indexer of DeepSeek-V3.2-style sparse attention, ERNIE 5.5 Flash's MLA layers included; requires SM100. DeepSeek V4's C4 indexer has its own switch, --enable-deepseek-v4-fp4-indexer. Default keeps the FP8 indexer. |
| --paged-experts-num-resident | --paged-experts-enable-disk | False | bool flag (set to enable) | Let Paged Experts write to disk under $SGLANG_CACHE_DIR/paged_experts: each MoE layer's experts are kept there (about the size of the experts), so that later starts read them instead of loading and repacking them. Requires --enable-paged-experts. |
| UocrDocumentConfig namespace (new, mm) | --uocr-doc-split | False | bool flag (set to enable) | Unlimited-OCR v2: opt into approximate page-window document processing with KV reuse. Requires a single data-parallel rank. |
| --uocr-doc-split | --uocr-doc-page-window | 1 | Type: int | Unlimited-OCR v2: maximum pages a split window transcribes, excluding lookahead pages. Applies to every image mode. Must be at least 1. |
| --uocr-doc-page-window | --uocr-max-page-tokens | 0 | Type: int | Unlimited-OCR v2: output-token limit per page. The built-in page guard enforces it without --enable-custom-logit-processor. Also sizes the default context of a split server. 0 disables the length limit. |
