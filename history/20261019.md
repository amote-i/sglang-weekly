## 新增参数

| 前一个参数/新参数分组 | 参数名称 | 默认值 | 可选值 | 描述 |
|---|---|---|---|---|
| --enable-custom-logit-processor | --enable-watermark | False | bool flag (set to enable) | Enable Aaronson-Gumbel text watermarking. |
| --enable-watermark | --watermark-config | None | Type: Optional[str] | Watermark settings as a JSON file path or an inline JSON object with optional key, key_b, context_window, mixing_probability, max_probability, default_enabled, and enforce_all fields. |
| --enable-lean-attention | --monokernel-backend | None | Type: Optional[str] | Select a registered monokernel backend, e.g. amd from sgl-amd-mono. Supported decode and verify steps use persistent kernels; other steps use the standard forward. An unsupported startup configuration raises an error listing the reasons. Experimental feature. |
| --enable-cp-decode-attn-tp | --enable-kv-cache-sharding | False | bool flag (set to enable) | Shard at-rest KV cache storage at page granularity across the group that currently replicates it (attention-CP ranks for GQA models under prefill CP; attention-TP ranks for MLA models), multiplying the group's unique KV capacity. Prefill workers of PD disaggregation only. |
| --enable-layernorm-sp | --enable-megamoe-for-layernorm-sp | False | bool flag (set to enable) | Use fused MegaMoE for Muse Spark NVFP4 TP4/EP4 or TP8/EP8 LayerNorm-SP prefill, including BF16 excluded layers. Decode retains the FlashInfer TRT-LLM MoE runner and all-reduce, sharing expert weights with prefill. Requires --enable-layernorm-sp, DeepGEMM with post-expert normalization, and NVLink/NVSwitch. No FlashInfer A2A backend is required when enabled. |
