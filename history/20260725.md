## 新增参数

| 前一个参数/新参数分组 | 参数名称 | 默认值 | 可选值 | 描述 |
|---|---|---|---|---|
| --dcp-size | --dwdp-size | 1 | Type: int | DWDP (Distributed Weight Data Parallelism) group size. When \> 1, MoE prefill uses weight prefetch instead of token all-to-all. Must equal tp_size. Only supported with --disaggregation-mode null or prefill. |
| --dwdp-size | --dcp-comm-backend | ag_rs | ag_rs, a2a, fi_a2a | Communication backend for the decode context-parallel (DCP) attention reduction: 'ag_rs' (AllGather + ReduceScatter), 'a2a' (fused NCCL All-to-All exchange of output+LSE + local Triton LSE combine), or 'fi_a2a' (FlashInfer MNNVL All-to-All kernel; requires SM90+ and MNNVL fabric memory, e.g. GB200 NVL72). |
| --dcp-comm-backend | --dcp-replicate-q-proj | False | bool flag (set to enable) | For MLA decode context parallelism with the a2a/fi_a2a backend: replicate the Q projection so each DCP rank computes the full-head query locally (redundant projection compute), eliminating the per-layer head-dim all-gather of Q. Trades a small amount of extra GEMM for one fewer collective per layer. |
| --enable-dsa-cache-layer-split | --enable-cp-decode-attn-tp | False | bool flag (set to enable) | Enable attention tensor-parallel weight slicing during decode under context parallel (cp_size\>1). Slices the replicated attention linears to the local CP partition, eliminating redundant decode GEMMs. |
| --grpc-port | --sidecar | None | Type: Optional[str] | Start a locally managed sidecar against the native gRPC server. The selected module must expose main(argv) and read the resolved native gRPC endpoint from SGLANG_GRPC_ENDPOINT. Requires --grpc-port or SGLANG_GRPC_PORT. |
| --sidecar | --sidecar-args | None | Type: Optional[List[str]] (JSON array) | JSON array passed to the selected sidecar module's main(argv) function. --sidecar-shutdown-timeout SECONDS is consumed by SGLang. |
| --enable-torch-symm-mem | --enable-scattered-sconv | False | bool flag (set to enable) | Inkling: replace the attention/MLP output all-reduce with a hidden-dimension reduce-scatter, run the channelwise output short convolution on the [T, H/P] shard, then all-gather before the residual add. This shards the convolution cache across tensor-parallel ranks without changing communication volume. |
| --mamba-ssm-dtype | --mamba-max-states-per-path | -1 | Type: int | Maximum number of cached Mamba states retained per root-to-tail path (-1 means unlimited). When enabled, after each insert the shallowest eligible interior states beyond the cap are removed while their full KV remains. Tail, fork, and locked nodes are preserved. Must be -1 or a positive integer. |
| --linear-replayssm-cache-len | --enable-gdn-replayssm-spec | False | bool flag (set to enable) | Enable the ReplaySSM GDN spec-verify kernel (Part B of RFC #28511): a per-slot circular (d, k, g) ring + periodic flush replacing the recurrent verify's per-draft full-state snapshots. GDN only, linear-chain (--speculative-eagle-topk in {None, 1}) only. Reuses --linear-replayssm-cache-len for the ring length. |
| --mm-process-config | --mm-processor-worker-num | 0 | Type: int | Number of threads for multimodal processor calls. 0 selects the model-specific default. Only processors with isolated-worker support can use more than one thread. |
| --mm-processor-worker-num | --mm-io-worker-num | 0 | Type: int | Number of threads for multimodal data loading and decoding. 0 selects the model-specific default. SGLANG_IO_WORKERS remains supported as an environment override when this argument is 0. |
| --engine-info-bootstrap-port | --modelexpress-config | None | Type: Optional[str] | JSON config for ModelExpress P2P weight loading. Keys: "url" (optional gRPC host:port override), "transport" ("nixl" or "transfer_engine"). Example: \'{"url": "localhost:8001", "transport": "nixl"}\' |
| --enable-mis | --weight-cache-mode | off | off, daemon, client | Weight cache mode. 'off': normal disk loading. 'daemon': launch weight cache daemon (holds weights in GPU memory). Engine-spawned daemons are co-terminal with the engine and do NOT persist across restarts, so this alone does not speed up restart (the first start is slower). For fast recovery, run the standalone daemon (python -m sglang.srt.weight_cache.daemon) and connect with 'client'. 'client': connect to existing daemon and load via IPC. |
| --weight-cache-mode | --weight-cache-socket | None | Type: Optional[str] | Unix socket path for weight cache daemon (client mode). If not set, uses /tmp/sglang_weight_cache_rank{global_rank}.sock |
| --weight-cache-socket | --weight-cache-timeout | 1800 | Type: int | Timeout in seconds for weight cache daemon readiness (default: 1800). |
