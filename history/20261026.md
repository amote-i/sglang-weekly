## 新增参数

| 前一个参数/新参数分组 | 参数名称 | 默认值 | 可选值 | 描述 |
|---|---|---|---|---|
| --enable-lean-attention | --enable-nvidia-megakernel | False | bool flag (set to enable) | Enable the NVIDIA megakernel from the sgl-nvidia-mega package. Supported decode and verify steps use its fused kernels; other steps use the standard forward. An unsupported startup configuration raises an error listing the reasons. Experimental feature. |
| --enable-nvidia-megakernel | --enable-amd-monokernel | False | bool flag (set to enable) | Enable the AMD monokernels from the sgl-amd-mono package. Supported decode and verify steps use persistent kernels; other steps use the standard forward. An unsupported startup configuration raises an error listing the reasons. Experimental feature. |
| --enable-dp-attention | --monokernel-backend | False | amd | [Deprecated alias for --enable-amd-monokernel] Deprecated. Use --enable-amd-monokernel instead of --monokernel-backend amd. |
| --enforce-shared-experts-fusion | --enable-paged-experts | False | bool flag (set to enable) | Keep only --paged-experts-num-resident routed experts per MoE layer on the GPU and page the rest from pinned host memory on demand. Single GPU; the experts must run on the triton or Marlin MoE runner (supported quantizations: see the Paged Experts docs). Decode CUDA graphs (full backend) are captured up to K // top_k requests; prefill graphs must be breakable or disabled. |
| --enable-paged-experts | --paged-experts-num-resident | None | Type: Optional[int] | Number of routed experts per MoE layer kept resident on the GPU. Required with --enable-paged-experts; at least the router's top-k. |
| --unified-cache-external-linker-backend | --unified-cache-external-linker-config | None | Type: JSON object | JSON configuration for the selected linker backend. Built-in backends accept storage options directly. The dynamic backend requires linker (class name), linker_module_path (Python module), and optional linker_extra_config (object). May be supplied while the linker is disabled. For built-in backends, replaces --hicache-storage-backend-extra-config when provided. The fallback to that flag for external linkers is deprecated; ordinary HiCache use of that flag is unaffected. |
| --prefill-decode-interval | --prefill-decode-interval-min-bs | 0 | Type: int | Apply --prefill-decode-interval only while the running batch holds at least this many requests. Below it, prefill is admitted every round so the batch fills quickly. In data-parallel attention mode, each rank compares its own running batch. Set to 0 to always apply the interval. |
| --fastapi-root-path | --enable-http-worker-reuseport | False | bool flag (set to enable) | Give each Uvicorn HTTP worker its own SO_REUSEPORT listener. |
